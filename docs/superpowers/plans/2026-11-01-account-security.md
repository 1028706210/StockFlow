# 账号安全阶段实施计划

目标：在现有本地演示和单实例架构内完成密码修改、管理员停用/启用账号、登录/注册及 Basic 失败限流。继续执行用户已经授权的逐项改进，不切换生产环境。

边界：不删除账号、不修改角色、不接短信/邮件找回；管理员不能停用自己或其他管理员；不在浏览器代替用户提交密码更改。自动化改密仅在专用测试库的合成账号上执行。

- [x] V008 在 app_user 增加 auth_version；更新密码和启停状态递增版本；已认证的受保护请求校验 enabled/version，旧会话返回401。
- [x] 复用现有 BCrypt、会话和审计，实现本人与管理员接口。审计只写操作与状态，不写密码或哈希；管理员列表分页，只返回公开账号字段。
- [x] 在 Spring Security 链中加入单实例限流：注册按实际来源地址；登录和 Basic 失败按来源+账号与来源总量；使用有界内存与固定窗口，不信任外部转发头。

验收限制：即时失效指下一次经过安全链的请求，已经执行中的事务不能撤回；进程重启会清除本机限流计数，多个实例需要共享存储或网关方案。正式公网配置、邮件找回和外部告警另行完成。
