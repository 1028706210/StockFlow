# 文字可读性与排版优化

基准d2e58e6，分支codex/readable-typography。用户明确要求放大文字、减轻阅读负担并改善美观；沿用浅色、6组导航和原有业务。

## 设计与范围

Product Design实际审查与Edge测量确认：正文14px、表格13px、搜索/操作12px、状态与编号11px。采用统一字号层级、行高与控件扩容；不增加字号切换器、远程字体或新视觉主题。

- 正文16px、表格15px、表头14px、辅助13–14px；主标题30px、手机28px。
- 输入/选择16px、主按钮15px、文字操作14px；主控件至少44px高。
- 导航16px，页内导航15px、手机14px；状态13px，编号13px，数字不拆行。
- 七日趋势保留13px数值与内部横滑空间，避免压成8px。表格需要时在容器内横滑，金额不任意断行。
- 买家手机导航自然分组为两列，隐藏重复面包屑；表单、商品详情及咨询文字同步调整。
- 直接维护styles.css、atmosphere.css、storefront.css和assets/ui/chat/chat.css现有规则，不新增依赖与业务逻辑。
