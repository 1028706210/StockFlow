# 浅色工作台与导航收敛设计

用户反馈：界面太多、同级入口冗余、深色主题增加负担；要求调用相关插件优化实际前端。沿用现有Java与原生JS，调整信息架构和视觉，不新增业务页面、框架或数据库改动。

## 当前审查

已使用Product Design的index、audit、user-context/preflight和get-context工作流。用户指定Edge优先，沿用其浏览器。提供的侧栏截图与本轮概览/库存截图显示：管理员13个同级入口，库存流程拆散；概览同时有宣传横幅、指标、待办和快捷操作；全页粒子与深色低亮度文字增加干扰。截图可判断可见层级，不能证明全面无障碍合规。

本轮内部证据：artifacts/light-redesign/01-before-overview.png、02-before-inventory.png。完整页截图可能呈现固定侧栏的滚动位置，布局比较采用相同视口的实际页面，不把该偏移当应用本身缺陷。用户原图直接支持入口数量与同级关系。

## 实施选择

采用6个一级入口＋上下文页内导航，优于只缩小旧菜单（仍要扫描13项）或新建一套聚合业务接口（无必要增加维护成本）。保留原路由、查询地址、浏览器前进后退与权限。

| 一级入口 | 保留的原路由/页内入口 |
|---|---|
| 工作台 | overview |
| 商品管理 | products |
| 库存中心 | inventory、ledger、alerts、stocktakes、reconciliation |
| 入库管理 | receipts |
| 订单管理 | fulfillment、returns |
| 系统管理 | audit；accounts/runtime仅管理员 |

仓管不出现管理员专属页；买家继续使用自己的商品、订单、退货和订购入口，不能显示仓管分组。旧深链接如#ledger仍进入原功能，同时选中库存中心及对应页内项。

## 视觉与减法

暖灰背景、白色内容区、深灰文字、低饱和青绿主色。统一颜色变量、边框、圆角、焦点与按钮状态；覆盖登录、表格、弹窗、买家端与咨询组件。保留轻微悬停，默认浅色不启动粒子调度，不写入新的持久偏好。

删除概览宣传横幅及重复快捷操作组件和对应无用渲染/绑定；保留真实指标、可操作待办、趋势和最近记录。减少装饰性英文标签，不改变指标与业务含义。

## 验证边界

导航分组、角色、深链接、退出清空和浅色不启动动效有行为回归。现有Node全套与Java构建/回归应保持通过。Edge检查概览、库存页内导航、订单/系统、登录及商品/单据弹窗；320像素页内导航、菜单键盘与表格滚动。未删除业务数据，不改密码，不切生产。完成后同步D盘、双仓库及新提交CI，保存真实截图和未覆盖项。
