# 实物订购前台与仓管后台对齐

2026-10-31。用户确认将8094改作StockFlow实物订购入口；序物设计素材作品保留在digital-store，不迁移其数字订单或删除收费素材。

## 入口与业务

| 入口 | 用途 |
|---|---|
| http://127.0.0.1:8082/ | 原仓管/管理员工作台，原买家工作台也保留 |
| http://127.0.0.1:8082/shop | 新实物订购前台，商品卡、订购单、本人订单、整单退货 |
| http://127.0.0.1:8094/ | 跳转到Java同源/shop，不代理账号、不存订单 |

前台和后台共用同一个Spring Security会话、商品、订单和MySQL库。下单预留、确认、仓管发货、买家收货与退货仍调用已有业务规则。没有新增付款、数字下载、促销或物流能力，也不向买家开放实存/预留/审计接口。

新前台沿用后台的深色、薄荷绿、细边框、按钮与状态；目录从管理表格调整为名称、编码、实际单价与选购操作组成的商品卡。没有杜撰照片、库存数字、销量或评价。商品查询失败时保留旧结果并禁用操作，切换身份时清空旧卡片。仓管身份访问/shop转回原工作台。

## 本机运行

先按README启动Java后台，直接打开 `/shop` 即可，不需要Node。

若要保留8094入口，在另一个终端执行（需要Node.js24）：

```powershell
node ./storefront/start.mjs
# Docker后台默认8083时先设置：
# $env:STOCKFLOW_BACKEND_URL='http://127.0.0.1:8083'
```

原素材商城要单独查看时使用其他端口，且BASE_URL与端口保持一致，例如在digital-store目录：

```powershell
$env:PORT='8095'
$env:BASE_URL='http://127.0.0.1:8095'
node server/start.mjs
```

### 页面与手机适配

- 桌面实际登录、浏览商品卡、打开商品详情、加入订购单、查看订单与退货详情。
- 商品查询无匹配时显示空状态，重置筛选和下一页可用。
- 手机复验使用 390×844、320×740 的浏览器视口；属于响应式模拟，并非实体手机测试。
- 发现原订单和退货表格受全局 `min-width:600px` 影响，详情按钮位于屏幕之外。仅在 `/shop` 的手机样式内压缩关键列，时间列仍可在详情中查看；保留表格语义和全部业务操作。
- 390 像素下订单表格可视宽/内容宽均为 338；320 像素下退货表格可视宽/内容宽均为 267，导航可视宽/内容宽均为 269。上述已检查页面没有整体横向溢出。
- 订单详情的商品、数量、单价、小计能在同一宽度中查看；手机分页控件允许换行，按钮文字不再纵向挤压。
- 手机咨询助手改为页面底部普通布局，避免浮动覆盖订单操作、分页或提交按钮。桌面保留原浮动入口。
