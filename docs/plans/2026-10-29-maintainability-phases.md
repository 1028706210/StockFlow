用户已同意分阶段推进。保留 Java 单体、原生 JavaScript 前端、现有外观和业务接口；先整理结构，再优化明确查询，随后补页面验收，最后评估是否有必要迁移 Vue。全部新增回复、文档和界面文案使用简体中文。

执行裁定：当前是已有功能的移动重构，保留原实现与既有行为测试，不为复制现有行为额外编写重复测试；改动前后运行相同回归并检查实际模块加载。沿用用户当前开发分支和未提交文档，不创建会丢失这些内容的新工作树。

## 第二阶段 查询与后端可读性

## 第三阶段 真实页面验收

尚未实施。浏览器控制可用时用 Edge 验收桌面与手机的入库、下单、履约、退货、筛选恢复、下载与对账。旧截图和 Node 测试不代替本轮实操。

## 第四阶段 Vue 评估

尚未批准迁移。依据页面扩充与维护成本决定是否逐页采用 Vue 3、TypeScript、Vite。继续使用既有 Java 接口、会话／CSRF及视觉风格，不同时拆微服务或改变数据库模型。
