# StockFlow 粒子视觉升级

方向：现有深色系统的视觉改版，Canva 粒子素材提供色彩和流向参考，Figma 保留可编辑登录与概览稿，实际用本地 Canvas 绘制动效。

范围：index.html、app.js 的展示节点及独立 atmosphere.css/ambient.mjs。沿用原生页面、登录注册、分页、库存与履约功能，不改后端、数据库或依赖。

要求：登录与概览有粒子光流；其他页保留安静数据区。细鼠标可交互，动效可暂停，遵循减少动态效果，后台/离屏停止绘制。维持键盘操作和手机布局。

验收：前端行为回归、动效调度测试、打包、实际桌面/手机、Figma/实际页面视觉比较。

完成：Figma 两张可编辑稿、Canva 粒子方向、前端61项验证、实际桌面/手机、暂停偏好、主要业务入口和打包检查；验收见 docs/particle-ui-qa.md。

后续用户调整：粒子扩展到所有界面，已覆盖全部8个工作台视图、登录/注册与弹窗。移除左侧亮度衰减，增加全域浮尘、三条流动带和鼠标连线。66项前端验证通过，实际逐页检查和手机检查见 docs/all-pages-particles-qa.md。原“其他页保留安静数据区”属于上一轮范围，本轮由用户新要求取代；以控制亮度保持可读性。
