# 独立展示环境

用途：招聘演示与学习，展示单仓订购履约；没有真实收款、物流或生产客户。

## 启动

Windows 安装 PowerShell 7、Java 17、MySQL Server 8、Node.js 24；首次打包还需要 Maven。运行：

```powershell
pwsh -File ./tools/Start-Showcase.ps1
# 可选 -Rebuild -Maven '你的Maven目录/bin/mvn.cmd' -MySqlHome '你的MySQL Server 8目录'
```

脚本复用本项目独立 MySQL 实例，建立单独的 `stockflow_showcase` 库与仅访问该库的账号；不使用课程库或 `stockflow_dev`。应用默认 8096，数据库默认 3308。需要换端口时在第一次运行传 `-HttpPort` 或 `-DatabasePort`；已有配置不自动改端口。JAR 及依赖缺失时按提示先打包。

买家入口 `http://127.0.0.1:8096/shop#products`，仓管入口 `http://127.0.0.1:8096/`。账号 buyer、buyer2、warehouse、admin，口令仅保存在本机 `.local/showcase.json` 的 demoPassword；不要使用开发库或 Docker 的口令代替。

日志、进程编号、私有配置均在 `.local/`，不提交代码仓库。关闭浏览器不会停止服务；停止时核对 `.local/showcase.pid` 及命令行确实指向本项目 JAR，再停止对应进程，不能结束全部 Java 进程。已运行服务不会被脚本自动重启；重建前先正常停止。

## 数据与重复运行

公开商品定义在 `tools/showcase/products.json`，含 8 个独立中文商品，带分类、规格、单位和说明。`tools/showcase/render-artwork.mjs` 以原创 SVG 路径绘制对应示意图，没有外部图片、脚本、素材库或付费元素。图片明确标注为示意，不代表实物照片、认证或经营中的商品。

脚本先以仓管身份读取 `/api/showcase/identity`，服务端同时要求开启展示标志和实际连接的数据库名为 `stockflow_showcase`。普通开发或测试库即使误开标志也拒绝展示准备。确认环境之前不创建商品或订单。

数据通过已有商品、正式入库单、订单、退货接口保存，具备正常权限、幂等、事务、快照、流水与审计。固定请求标识保证重复执行不重复入库或下单。既有商品不改名、不覆盖资料；只对清单中的固定展示商品幂等校准安全库存；已变化的订单不倒退状态，未确认订单仍遵循 15 分钟超时规则。准备中断可以重试；若状态已发生冲突，应检查提示，不清库绕过。

8 个商品含一个低库存案例；5 笔订单分别尝试建立待确认、已确认、已发货、已完成、已取消场景，已完成案例另包含整单退货回库。它们全部是演示操作。脚本打印实际单号和当前状态，不保证过去生成的待确认订单永久保持待确认。

## 商品资料边界

分类、规格、单位和说明由仓管维护，买家只读；新订单保存规格和单位快照。旧单的缺失信息不回填当前商品值。更换实际商品型号或计量方式时应新建 SKU，不能用编辑说明替代库存换算；本项目没有变体、拆包或单位换算功能。

当前商品图片仅为固定展示商品提供原创示意图，不开放上传或远程图片 URL。一般商品仍可完整显示文字资料。V007 只新增列，不删除旧数据或重写已执行迁移。

Docker 主运行方式仍见 README，独立展示准备脚本当前面向 Windows 本机 MySQL，不把这点写成跨平台已验收。
