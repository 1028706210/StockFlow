# StockFlow 项目文档中心

StockFlow 是面向 Java 后端实习与校招展示的单仓库存与订单履约系统。本套文档供开发者、测试者、演示者及技术评审使用，说明系统要解决的问题、已实现的规则、设计依据和交付边界。

2026-10-31 更新阅读入口。主要章节和总册原始编制基准为 `33c830f`（2026-10-29），现行代码已在 `main` 发布；后续买家界面修正和真实验收见下方增量记录。需求编号用于追踪，不代表文档已经正式审批。

## 状态标记

- **已实现**：可在基准版本代码找到实现；不等于所有环境已验收。
- **已有验证**：有具体提交、测试报告、HTTP 记录或 CI 结果支持。
- **待验收**：有实现或验收步骤，但缺少对应版本的实际执行证据。
- **建议／规划**：后续工作，不计入目前功能。

2026-10-29第一阶段结构整理已重跑89项前端测试、完成打包和匿名模块HTTP检查；没有重跑后端全套。

2026-10-31 核对已发布提交 `f3f968f` 的 [CI](https://github.com/1028706210/StockFlow/actions/runs/41173280488)，`mysql-tests` 与 `container-smoke` 均为 success。2026-10-30 已补充入库、履约、收货与退货回库的部分真实 Edge 操作及接口交叉核验，见[链路记录](../evidence/2026-10-30-lifecycle.json)；该文件列出的剩余项目未自动视为完成。买家范围验证见[专门记录](../buyer-scope-qa.md)。

## 文档维护

代码、迁移及测试是实现依据。功能变更时同步更新需求条目、业务规则、接口、数据字典及相应测试，然后更新本页基准与变更记录。`docs/plans`、`docs/specs`、`docs/*-qa.md` 保留历次决策与验证，本目录负责现行阅读入口。

完整源码现已发布在 [GitHub main](https://github.com/1028706210/StockFlow) 和 [Gitee main](https://gitee.com/DAD323/stock-flow)。PR 1 与阶段文档保留开发历史；当前默认分支已经包含主项目与独立数字商城，不能再用“仅开发分支有代码”的旧说明。
