# 库存流水与预警验收 — 2026-10-25

## 实现与范围
- 沿用 Java17 / Spring Boot / MyBatis / MySQL 与原生前端，无新依赖、无数据库结构迁移。
- 复用 inventory_ledger，查询隐藏 operationKey，只允许仓管/管理员。
- 预警查询全量在售 SKU，available < threshold，默认10；阈值1..1000000，查询时生效，不持久化规则。
- 流水和预警均支持名称/编码搜索，按编号倒序每页20条；接口允许1..100条。
- 炭灰底色、薄荷强调色、状态标签、暗色表单、精简悬停反馈、手机换行、长账号省略。
