# 浅色工作台与导航说明

本轮针对界面入口多、层级不清和深色干扰进行调整。业务功能和原路由仍在，改变的是入口组织与默认视觉；没有添加数据库表、第三方前端依赖或新的业务接口。

## 功能入口

| 侧栏一级入口 | 页内功能 |
|---|---|
| 工作台 | 真实指标、待办、业务趋势、最近记录 |
| 商品管理 | 商品查询、详情、维护及入库入口 |
| 库存中心 | 库存总览、变动流水、补货预警、库存盘点、库存对账 |
| 入库管理 | 入库单列表、草稿和确认 |
| 订单管理 | 订单履约、退货处理 |
| 系统管理 | 操作记录；管理员另有账号管理和运行状态 |

买家继续使用商品目录、本人订单、退货和订购单，不出现仓管模块。仓管不能访问管理员专属功能。`#ledger`等旧深链接仍进入原功能，并自动突出库存中心与对应页内链接。页内链接是普通导航，支持浏览器前进后退和键盘Tab，不冒充需要方向键操作的ARIA标签页组件。

## 视觉与维护

- 白色内容区、暖灰页面背景、深色文字、青绿强调色，使用现有本地字体与Lucide图标。
- 默认浅色，不读取或覆盖旧粒子偏好，也不建立Canvas、观察器或动画循环。旧动效引擎保留原有测试，当前页面不启用。
- 删除重复宣传和快捷操作，保留指标真实含义。累计指标、业务数量不因主题变化重新定义。
- 登录、商品详情、盘点弹窗、编号复制、分页、买家端与咨询组件统一配色。手机顶部隐藏易换行的账号辅助标签，保留账号安全与退出；咨询入口放到页面底部。
- 主题文件继续使用 `assets/ui/atmosphere.css`；基础布局在styles.css，买家结构差异在storefront.css。主题最后加载，storefront专属边距和菜单使用明确场景覆盖，避免通用规则抢占。
- 修改导航时维护workspace-navigation.mjs中的角色和分组，原权限仍由路由及Java服务端控制。

## 验证与当前运行边界

本地Node共149项通过（StockFlow121、独立商城28），包括分组/角色/深链接/退出清空和浅色不启动粒子。Edge已操作概览、库存流水、盘点弹窗、系统和订单组，以及买家商品详情；320像素库存页面无横向溢出，5个页内入口均为44像素高。商品详情Escape关闭、手机菜单Escape关闭与焦点恢复已检查。

独立只读审查发现买家页216像素空白边距及手机无效菜单，两项均在浏览器复现并通过更明确的浅色storefront规则修复。额外修正了编号和分页残留旧样式、账号标签窄屏换行及咨询按钮遮挡。

当前完整项目入口为 `http://127.0.0.1:8096/#overview`，买家入口为 `http://127.0.0.1:8096/shop#products`。新版JAR已替换到D盘展示实例，数据库就绪状态为UP；重启前核对了监听端口与JAR完整路径，旧JAR保留在本机私有目录。原8097源码预览仅用于改版中间验收，认证和CSRF始终由真实Java后台处理，没有模拟业务成功。

用户授权后，本轮本地Java verify和打包已成功：123项检查、122项通过、1项跳过，失败和错误均为0；跳过项是未开启的大数据证据测试，不将跳过算作通过。D盘与构建输出JAR的SHA-256一致。Edge又在8096最终入口确认了浅色主题、6个侧栏入口、库存5个子入口及320像素无横向溢出。当前辅助文字在白底对比度约5.27:1、页面背景约4.84:1；这不是全面无障碍认证。
