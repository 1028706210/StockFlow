# 账号安全与维护

本阶段用于现有单实例、本地演示系统。实现密码修改、账号启停与有界限流，不等于已完成公网安全审计或生产上线。

## 使用方式

- 登录后，买家和仓管顶部均有“账号安全”，输入当前密码、新密码及确认密码。
- 新密码为 8–64 个字符、UTF-8 不超过72字节，不能全为空白，不能与旧密码相同。密码保留首尾空格，不自动修剪。
- 修改成功后需要重新登录；其他旧会话在下一次请求时失效。
- 只有管理员能进入“账号管理”，按账号名称查询、分页、停用或启用买家/仓管账号。不能停用本人或其他管理员，不提供角色分配、账号删除。
- 停用保留订单和历史记录；重新启用也不会恢复旧会话，需要重新登录。

## 接口

| 方法与路径 | 权限与结果 |
|---|---|
| POST `/api/auth/password` | 当前登录人；JSON `currentPassword`、`newPassword`；浏览器要求CSRF；成功204并撤销会话 |
| GET `/api/admin/accounts?q=&page=1&size=8` | 仅管理员；名称最长32，分页1–50；只返回id、username、role、enabled |
| PUT `/api/admin/accounts/{id}/enabled` | 仅管理员；JSON布尔字段enabled；重复相同状态不重复递增版本 |

新错误码包括 CURRENT_PASSWORD_INVALID（400）、PASSWORD_REUSED（400）、ACCOUNT_PROTECTED（409）、RATE_LIMITED（429）、ACCOUNT_CHECK_UNAVAILABLE（503）。限流响应带 Retry-After，前端显示服务端等待秒数。账号不存在与无权限继续遵循原有404/403规则。

## 会话撤销

V008 给 `app_user` 增加 `auth_version`，默认0，不修改既有密码、角色或启用状态。改密及启停变化在事务内递增版本；认证身份保存登录时版本，已认证的受保护API请求检查当前启用状态与版本。明确公开的页面壳与静态文件仍可加载，避免旧会话刷新时无法显示登录界面；它们不包含受保护的业务数据。不缓存密码哈希到账号列表，也不回填旧口令。

失效边界是下一次经过安全链的请求；已经执行中的业务事务不会被撤回。账号状态无法从数据库核验时返回503，不继续执行受保护操作。服务重启不会重置密码、启停状态或认证版本。

改密与启停审计分别为 ACCOUNT_PASSWORD_CHANGE、ACCOUNT_STATUS。审计仅保存账号与状态结果，不保存密码、哈希或改密请求正文。失败认证日志只含事件与requestId，不写明文口令、Basic头或请求正文。

## 单实例限流默认值

窗口为10分钟；计数直接使用当前服务看到的来源地址，本过滤器不读取 X-Forwarded-For 等客户端头。

| 场景 | 默认限制 |
|---|---|
| 同一来源＋账号，登录及Basic认证 | 失败数＋正在验证数最多8；成功释放许可并清除该账号失败计数 |
| 同一来源的所有账号认证 | 失败及在途合计最多80；成功不清除来源累计失败计数 |
| 同一来源注册 | 最多50次请求，包含字段不合法的尝试 |
| 同一来源＋身份改密 | 最多8次请求，另叠加实际Basic认证预算（如果提供Basic） |
| 内存容量 | 最多4096个键，过期清理；满额时暂时拒绝新尝试，不淘汰有效计数绕过限制 |

原子许可在认证前登记，并在 finally 完成，防止一批并发请求同时绕过检查。只有在途额度暂满时建议1秒后重试；失败预算耗尽时等待窗口到期。登录表单账号名与实际认证一致地去掉首尾空白，密码不修剪。Basic预算在注册、改密等路径同样生效，不能靠切换路径绕过。

可用 `stockflow.auth.failure-limit`、`stockflow.auth.register-limit`、`stockflow.auth.max-keys` 配置。仅测试profile将普通业务认证预算设为64，以运行已有32路Basic库存竞争；安全专项显式设为3验证严格限额，运行默认仍为8。

当前限制只在单进程有效；重启清空限流计数，多实例需要共享存储或网关。共享来源地址可能互相影响；部署反向代理前需确认可信转发边界，不能盲目信任任意转发头。这些限制不是绝对防攻击承诺。

## 未实现与验证边界

短信/邮件找回、管理员重置密码、角色分配、外部安全告警及生产HTTPS配置未在本阶段实现。不把启停账号描述成完整用户权限管理平台。

自动改密测试只作用于专用测试库合成账号；浏览器验收检查改密弹窗和输入规则，不代替使用者修改已有账号口令。最终结果与未覆盖项见验证索引。
