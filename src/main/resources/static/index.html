如何使用 StockFlow

  1. 以 warehouse 或 admin 登录

    在商品管理创建商品，在库存管理为商品入库。

  2. 切换 buyer 登录

    在创建订单中选择商品和数量，提交后查看订单及服务端金额。

  3. 体验安全重试与数据隔离

    重试本次下单会返回原订单；切换 buyer2 后，只能查询 buyer2 自己的订单。

当前版本尚未提供订单确认、取消、自动释放预留或发货。
