# 序物设计 SVG 素材设计与交付规范

版本：1.0.0。日期：2026-10-30。适用商品：C `c-icons`、D `d-decor`。

## 设计意图

采用现代编辑式视觉：清晰网格、充足留白、简洁几何路径。图标帮助小商家表达购物和服务流程；装饰为品牌活动、礼物、标签与社交排版提供不同结构。全部图案在本项目中独立编写几何路径，未复制图标库，也未使用外部图片或图片生成模型。

## 统一视觉

| 项目 | 规则 |
| --- | --- |
| 颜色 | 纸白 `#F5F2EA`、墨色 `#192923`、深绿 `#2E5D4B`、橙红 `#D96340`、浅橄榄 `#D9E4B8`、暖灰 `#E7E1D4` |
| C 图标 | `viewBox="0 0 24 24"`；1.75 描边；圆端点、圆连接；透明背景；默认墨色 |
| D 装饰 | `viewBox="0 0 160 160"`；透明背景；绿色主线、橄榄填充、橙色点缀；2 为基础描边，2.5 与 3 用于结构强调 |
| 预览排版 | 1600 × 1200；纸白底；深绿文字；细分隔线；统一四列总览 |
| 中文预览字体 | 仅在本机通过微软雅黑渲染，不向交付包复制或嵌入字体文件 |

## 真实素材目录

C 的 12 个不同用途：品牌门店、购物手提袋、打包纸箱、同城配送、新品吊牌、订单票据、支付卡片、在线客服、活动日历、心意礼盒、便捷退换、安心保障。

D 的 12 个不同构图：日光印章、拱形边框、折角缎带、双枝花环、双凹口票券、花瓣封签、转角留白、手绑蝴蝶结、星芒组合、斜生枝叶、交织方纹、环绕椭圆。

每个素材有独立 SVG，使用真实 `path`、`rect`、`circle`、`ellipse` 或 `polygon`。不同构图不依赖改色或旋转同一图案凑数。D 中重复的星芒、叶片等基础语汇属于同一图案内部的构图语言。

## 私有交付

每个商品目录 `private/products/{商品ID}/` 包含：

- `svg/`：12 个源文件。
- `png/512/` 与 `png/24/`：C 的大尺寸透明图和实际基准尺寸检查图，各 12 张。
- `png/1024/` 与 `png/256/`：D 的大、小尺寸透明图，各 12 张。
- `overview.png`：真实成品总览。
- `manifest.json`：12 个素材的路径、用途、尺寸、渲染器版本和文件 SHA-256。
- 简体中文 `README.md`、`LICENSE.md` 授权草案。
- `download.zip`：包括以上全部文件，排除 ZIP 自身，内部使用相对路径。

`manifest.json` 的文件清单排除自身与 ZIP，以避免递归校验；ZIP 内包括 manifest。每包应有 41 个私有文件，ZIP 包内 40 个文件。

## 公开预览边界

`public/previews/{商品ID}/` 仅允许 `cover.png`、`overview.png`、`detail.png`、`usage.png` 四张合成 PNG。源码、独立透明 PNG、清单、授权草案、压缩包均保留在 private。

预览中的图案必须取自商品 SVG 实际渲染。封面使用主图与缩略图，overview 展示全部 12 件，detail 展示真实放大与编辑配色示意，usage 将真实图案放进示例排版。示例排版与示例文字不作为额外模板商品交付。

## 生成与验证

使用本地 Python 3.12、Pillow、Node.js 24 与 sharp / librsvg；未安装新的项目依赖、未调用付费生成。当前捆绑运行库没有 `@resvg/resvg-js`，因此选用已核实可用的 sharp 0.35.5 / librsvg 2.63.2 从真实 SVG 渲染。Pillow 只合成预览，不生成或冒充矢量路径。

在商城根目录，用可用的 Python 运行：

```powershell
python scripts/build-svg-goods.py
python scripts/build-svg-goods.py --validate-only
```

若系统没有 `python` 命令，可调用本机捆绑解释器的完整路径。`--runtime-root` 可以指定包含 `node/bin/node.exe` 和 `node/node_modules/sharp` 的本地依赖目录。

脚本实际执行下列校验并输出逐商品结果：XML 可解析、SVG 数量、viewBox、统一图标描边、圆端点和连接、允许节点清单、禁用 image / script / foreignObject / 外链 / 事件属性 / 样式与 URL 引用、排除同色化后的重复几何；PNG 数量、尺寸、透明背景和非空内容；manifest 文件集合与 SHA-256；ZIP 完整性、路径、文件集合和逐文件字节比对；公开目录只有约定的四张 PNG。

自动校验只能证明结构、交付一致性与基本安全边界；视觉清晰度仍需通过实际 PNG 查看。经营者尚需审核价格、商标与正式授权条款，本地生成不代表已发布或已具备正式销售许可。
