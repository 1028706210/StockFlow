# 序物设计商城设计与实施计划

日期：2026-10-30。品牌“序物设计”为工作名称，商标、域名、经营主体、地区、币种、定价、政策和付费预算待经营者确认。默认不付费、不公开发布、不启用真实收款。

## 目标与架构

在 StockFlow 基础上新增独立的数字商城模块；复用已有原生 ES Modules 的轻量开发方式，数字商品不占用实物库存，不复用确认订单即发货的模拟流程。

工作目录位于当前可写工作区“序物设计商城”，完成后整理到 StockFlow/digital-store。前端为简体中文 HTML/CSS/ES Modules，服务端 Node.js 24 内置 HTTP、SQLite、Crypto；只维护结算对应关系和下载授权，支付页面复用托管 Checkout，不自建卡片输入或完整账户系统。公开目录仅放 PNG 预览和产品元数据，源文件、ZIP、Canva 管理链接位于私有目录。

## 统一设计规范

- 风格：现代编辑式设计，大留白、清晰网格、细线图形，适合独立品牌和小商家。
- 颜色：纸白 #F5F2EA、墨色 #192923、深绿 #2E5D4B、橙红 #D96340、浅橄榄 #D9E4B8、暖灰 #E7E1D4。
- 字体：中文优先 Noto Sans SC，系统无衬线回退；不打包未经核实的字体文件。
- 原创图标：24×24，统一 1.75 描边、圆端点和圆连接，无外链、脚本、位图和无用滤镜。
- 装饰：统一 160×160 viewBox，12 个不同构图，适合社交模板和促销排版。
- 商品 A：a-social，6 页 1080×1080：品牌介绍、新品发布、三点卖点、活动邀请、使用步骤、品牌宣言。
- 商品 B：b-promo，4 页 1080×1350：新品促销、组合优惠、活动报名、节日促销。示例价格属于模板示例，非本店售价。
- 商品 C：c-icons，12 个不同用途的原创 SVG 商家图标。
- 商品 D：d-decor，12 个不同构图的原创 SVG 装饰。

## 文件与接口约定

- public/catalog.json：最终真实商品列表，必须从实际文件清单生成，不凭空写卡片。
- public/previews/{商品ID}/cover.png、overview.png、detail.png、usage.png：从成品生成。
- private/products/{商品ID}/：付费商品源文件、PNG 预览、清单、说明、授权草案和 download.zip。
- private/canva-designs.json：真实 Canva 管理链接、模板复制链接状态；不进入公开商品数据。
- API：GET /api/catalog，POST /api/checkout {items:[商品ID],requestKey}，GET /api/order 使用 HttpOnly 会话或恢复凭据，GET /api/download/{商品ID} 关联已验证订单，POST /api/webhooks/stripe 验证原始请求签名。
- 前端路由：#/、#/products、#/product/{商品ID}、#/cart、#/order、#/delivery、#/faq、#/contact、#/license、#/privacy、#/terms、#/refund。
- 商品元数据：id,title,category,subtitle,description,pageCount 或 assetCount,formats,dimensions,editable,requirements,included,previews,suggestedPriceMinor,currency,priceConfirmed,fulfillmentReady,saleStatus。

## 风险与验收重点

1. Canva 编辑链接不能作为买家复制链接；未核实的链接绝不公开或发货。
2. 付款跳转页面不能产生下载权限，服务端签名和平台回查共同确认。
3. 订单恢复凭据只进入 HttpOnly Cookie 或恢复表单，不能进入日志和公开前端包。
4. 私有源文件即使被猜到路径也不能通过静态服务读取。
5. 地区、币种、税务、退款及隐私保留草案；未审核不启用正式销售。
