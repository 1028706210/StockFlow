# 序物设计 · 原创数字素材商城

本地可运行的原创数字素材商城，新增于 StockFlow 项目目录中的独立 `digital-store` 模块。现有 StockFlow 库存、履约代码与数据库不参与数字商品交易。

**当前状态：4 个商品有真实本地文件；2 个 Canva 原稿已创建并核对页数、尺寸、文字编辑及整套网格预览；商城主要页面已通过本地 Edge 桌面与手机检查；本地结算协议与真实 ZIP 交付演练通过。Canva 买家复制和支付平台沙箱未完成，真实收款未开通，未公开上线。**

“序物设计”为工作名称，商标和域名没有完成可用性核验。建议价、CNY 币种、经营主体、销售地区与条款均待确认，不能据此直接营业。

## 启动

运行需要 **Node.js 24**，没有第三方网站运行依赖，无需 npm install。

```powershell
cd D:\project\StockFlow\digital-store
node --env-file-if-exists=.env server/start.mjs
```

打开 `http://127.0.0.1:8094/`。也可运行 `启动商城.ps1`；未设置 .env 时收款默认关闭。关闭终端或 Ctrl+C 会停止该服务。

工作区制作源目录为 `C:\Users\李帅朋\Documents\ChatGPT\自动化测试平台\序物设计商城`，运行命令相同。不要只双击 index.html，也不要使用把整个项目暴露为静态文件的服务。

- 首页、商品目录与分类/搜索、4 个商品详情、真实预览切换。

## 技术选择

前端使用原生 JavaScript ES Modules、HTML/CSS，不引入新框架；后端 Node.js 内置 HTTP、SQLite、Crypto 与 fetch。支付采用托管 Checkout 的候选适配，不自建银行卡表单。持久化仅负责结算快照、会话授权、回调去重与下载权限。

本轮使用 Canva 连接器导入原创 PPTX、检查并测试文字编辑；Python/python-pptx/Pillow 制作可编辑版式；代码原创 SVG，sharp/librsvg 实际渲染；Node 测试验证 HTTP、SQLite 和文件交付；浏览器工具实际操作 Edge，检查桌面、手机与 Canva 画布。Sites 技能采用本地开发分支，未创建或发布托管网站。未消耗付费生成额度。

```powershell
node --test tests/*.test.mjs

node scripts/verify-build.mjs
python scripts/build-svg-goods.py --validate-only
```

支付测试使用受控外部响应，明确不等于支付平台沙箱。本地演练使用独立临时库，不向商城开发库写入虚假订单。`docs/evidence` 保存结果。

重新制作商品需 Python、Pillow、python-pptx，以及 SVG 渲染器 sharp。生成脚本会重建对应商品文件，修改前保留自己调整过的作品；不应运行生成器覆盖已运营商品。重建模板后需要重新导入 Canva，不能将旧核验状态自动当成新文件核验。

## 部署与上线

依次阅读 `docs/运行与部署.md`、`docs/支付接入.md`、`docs/Canva交付与管理.md` 和 `docs/验收记录与上线待办.md`。只有地区、收款平台、币种、定价、政策、模板复制和平台沙箱确认后，才能申请正式发布与真实支付授权。
